## 1. 定时器参数推导

T = (PSC + 1) * (ARR + 1)/72000000 得PSC = 72 - 1，arr = 20000 - 1。分辨率也高。


## 2. 角度 → CCR 映射

CCR = 500 + angle / 180 × 2000   

### 防顶限位

设置`SERVO_MIN_US` / `SERVO_MAX_US` 为 550 / 2450。

| 信号 | 接到 |

| 舵机 棕线（GND） | 独立电源 GND |
